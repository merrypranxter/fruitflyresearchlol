# FRUIT FLY RESEARCH LOL 🪰🧠

**A research vault for connectome-derived artificial life, impossible bodies, and neural-driven generative art.**

This is the **research/reference repository**, not the production app. The companion implementation is `merrypranxter/neural_art_lab` (verify the actual repo path/access before assuming its code or state).

**Project question:** What can a biologically derived fruit-fly neural circuit control when it no longer has to inhabit a fruit fly?

We are interested in genuine causal neural contribution to autonomous experiments—not an animation that plays independently while a fly connectome flashes in the background.

## PROJECT PRINCIPLES

- **HANDS OFF** should eventually mean an agent chooses actions based on ongoing neural/world feedback, not merely a preset animation.
- Neural network, sensory encoder, motor decoder, local body controllers, physical world, and learning machinery remain individually identifiable and measurable.
- The same neural system should be swappable across bodies: fly, eight-tentacled soft organism, pigment-eating alien, particle cloud, or bodyless dynamical field.
- Worlds should be programmable: reaction–diffusion, phase separation, crystals, fluids, cellular automata, fractals, waves, multimaterial ecology, and more.
- Maintain a distinction between **working implementation**, **proposed engineering**, and **speculative research**.
- Save seeds, parameters, neural outputs, interventions, and world checkpoints to make experiments reproducible.
- Compare the intact neural controller against suitable shuffled/rewired/random or decoder-only controls.
- Design for interactive mobile use when possible, but do not assume a full 166k-neuron/125M-contact connectome fits an iPhone at real-time rates.
- For finished art, allow offline high-resolution rerender/export (PNG/GIF/MP4) separately from simulation resolution.
