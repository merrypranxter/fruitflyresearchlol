## Desired product
A modular **impossible vivarium / nervous-system playground** where the user can:
- choose a neural substrate or control condition;
- connect it through declared synthetic senses and action channels;
- give it a body, or no body, or a mathematical/material body;
- select coupled fields/materials and an environment;
- press **HANDS OFF** and observe genuine ongoing closed-loop consequences;
- intervene, mutate, compare brains, branch a timeline, breed experiments and watch multiple organisms;
- preserve histories, export art, inspect exactly which choices were neural, learned, scripted or random.

The user values mathematically authentic visual evolution, surprising but explainable results, eye-searing color, high resolution, responsive UI on phone, user-adjustable parameters, and real experiments rather than canned presets.
